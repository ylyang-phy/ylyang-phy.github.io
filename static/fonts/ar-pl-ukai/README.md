# AR PL UKai title font

`ar-pl-ukai-cn-title.ttf` is a webfont subset of the proportional **AR PL
UKai CN** face. It contains only `杨` (U+6768), `逸` (U+9038), and `伦`
(U+4F26), the three Chinese characters used in this site's title.

The source is the Debian/Ubuntu `fonts-arphic-ukai` 0.2.20080216.2 package:

- Source archive: <https://archive.ubuntu.com/ubuntu/pool/main/f/fonts-arphic-ukai/fonts-arphic-ukai_0.2.20080216.2.orig.tar.bz2>
- Source SHA-256: `b4968d73519f4f8747e85548fb85d21b665da1bf1ba900a7c499976e6a8ae3d2`
- Face: font 0 (`AR PL UKai CN`) from `ukai.ttc`
- Modification date: 2026-08-20
- Modification: subset with fontTools to U+4F26, U+6768, and U+9038

The modification notice is also embedded in the font's description metadata.
